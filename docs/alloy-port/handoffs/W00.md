# W00 — Hop harness + `[hop]` tracing permanent and opt-in

Status: done (2026-10-14). Not committed.

## What changed
- `Common/HopTrace.cs`: now permanent. `public static readonly bool Enabled = REALM_HOPTRACE == "1"` (line 20).
  Every public entry point returns at once when it is off, and `Now()` returns 0 when it is off.
- Call sites are gated on `HopTrace.Enabled` before any timestamp, string or helper call:
  `Common/Database.cs:291-293` (writer batch), `:919-934` (SetKey), `:945-961` (GetKey);
  `Networking/Client.cs:242, 353, 401, 853, 872, 876`; `Networking/GameServer.cs:223, 270`;
  `Networking/GameServer.Handlers.cs:262-273, 517-732`.
- `tools/hop/server_ctl.sh` (rewritten): runs the server with cwd `$STATE/run-<variant>`, using a generated
  `Settings.xml` (alternate ports 7877:2060) and a `Resources` symlink into `bin/<cfg>/net8.0`. It never
  writes under `bin/`. Options: `--config Debug|Release`, `--trace on|off`. It refuses to start if a port
  is busy, and it signals only the PID it recorded, after checking that PID's cwd.
- `tools/hop/run.sh` (new): one command that builds, starts the server, runs the hops, stops the
  server and analyzes the results.
- `tools/hop/analyze.py`: adds `--max-median-ms N` and `--max-ms N`, which exit 1 when exceeded.
- `tools/hop/README.md` (new). `hop_client.py`, `sqlite_overlap_repro.py` and `baseline/` are unchanged.

## Decisions
- **The DB root is `${REALM_HOP_DB_ROOT:-~/.cache/realm-hop-db}/<variant>`, not `${TMPDIR:-/tmp}`.** On this
  machine `/tmp` is tmpfs, and a tmpfs DB hides the fsync stall (~50 ms). Logs, pids, run dirs and settings
  stay under `${TMPDIR:-/tmp}/realm-hop`. The DB dir is wiped on each start, but only when it carries the
  `.realm-hop-owned` marker.
- `run.sh` builds into `bin/<cfg>/net8.0`, as `./debug` does. Pass `--skip-build` when a live server is
  running from that directory.
