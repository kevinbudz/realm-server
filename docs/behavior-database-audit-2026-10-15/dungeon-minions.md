# Shared dungeon minion behavior comparison

Compared target `kevinbudz/realm-server` at `bb75bc1e438b465986a8ada354b6332f69e0e3a6` with the candidate reference `ossimc82/fabiano-swagger-of-doom` at `6fd20aad4a7905b13f25389c68368a942a2b68cb` (2015-11-09). This is a definition-level comparison of shared IDs in the nine requested modules; it is not historical proof that the target differs incorrectly. Each paired reference module is included in the checked-in `wServer.csproj`. Principal boss behavior chains are listed for coverage but left to the dungeon boss comparison.

## Interpretation
